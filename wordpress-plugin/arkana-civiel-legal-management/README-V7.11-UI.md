# V7.11 Management UI/UX Overhaul

## Goal
Replace the utilitarian V5.3 executive dashboard presentation with a premium legal-tech command center while preserving the existing management metrics and permission boundary.

## UX direction
- premium law-firm visual language
- dark navy executive hero with restrained gold accent
- KPI cards with visual hierarchy
- Matter Workspace
- Service Delivery / Legal Requests
- Risk Center
- Firm Snapshot
- AI Management Copilot surface
- Quick Actions
- responsive desktop/tablet/mobile layout

## Preserved behavior
The redesign does not change the underlying Matter, Client, Retainer, Task, Request, Document, or authorization data model. Existing aggregate metric methods remain the source for KPI values.

## Important note
The preview rows and labels in the visual dashboard are presentation placeholders for the current demo experience. They must be replaced by live query-backed lists before production use.
