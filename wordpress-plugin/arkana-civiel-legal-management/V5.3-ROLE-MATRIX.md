# V5.3 Role Boundary

| Role | Executive Dashboard |
|---|---|
| Managing Partner | Full access |
| Partner | Full access to V5.3 aggregate view |
| Lawyer | No executive dashboard |
| Paralegal | No executive dashboard |
| Finance | No executive dashboard |
| Client Admin | No access |
| Client User | No access |
| WordPress Administrator | Technical access |

V5.3 is intentionally aggregate-only. Detailed matter/client authorization belongs to the permission and isolation layers scheduled for V5.12.
