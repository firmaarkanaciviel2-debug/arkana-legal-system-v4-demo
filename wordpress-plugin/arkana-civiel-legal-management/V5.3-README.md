# V5.3 — Managing Partner Executive Dashboard

## Purpose
Provide a WordPress admin executive view for Managing Partner users without exposing raw matter/document content.

## Dashboard metrics
- Active Clients
- Active Matters
- Active Retainers
- Open Tasks
- At-risk Deadlines
- Critical Legal Requests
- Matters On Hold
- Firm totals for clients, matters, requests, and documents

## Security boundary
V5.3 is an aggregate operational dashboard. It must not be treated as production-ready for sensitive client data until V5.12 completes matter-level authorization, client isolation, private document delivery, audit logging, and security hardening.

## Local QA
1. Install/activate the V5.1/V5.2 foundation plugin.
2. Activate `arkana-civiel-executive-dashboard.php` as a companion plugin.
3. Sign in as a Managing Partner.
4. Open **Legal Management → Executive Dashboard**.
5. Verify the metrics reflect the current test records.
6. Sign in as Client Admin/Client User and verify the Executive Dashboard is not available.
7. Test zero-data state: all metrics should render as 0 without fatal errors.
8. Test responsive layout in the WordPress admin viewport.

## Important implementation note
The current alpha uses aggregate WordPress queries and post-meta. It intentionally does not expose document content or provide client-facing access. Matter-level filtering and auditability are later security milestones.
